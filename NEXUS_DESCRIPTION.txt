DESCRIPTION
------------------------------------------------------------
Your Twitch and TikTok viewers earn chaos points just by watching -- then
spend them to sabotage (or occasionally bless) your farm in real time. Full
in-chat shop (!balance, !shop, !buy, !info), live OBS browser-source
overlays for chat/shop/TikTok redemptions, dozens of sabotages and
blessings up to the 50,000pt Nuclear Chaos finale, a togglable Animal
Challenge mode, and alpha co-op multiplayer targeting so other streamers in
your session can get their own chat-linked farmhand.

AI disclosure: NeighborhoodofMusic wrote the baseline code for this mod.
Claude (Anthropic) was used to help sort, organize, and correct the code.

====================================================================

INSTALLATION INSTRUCTIONS
------------------------------------------------------------
1. Download the zip below and unzip it anywhere.
2. Right-click Install.ps1 and choose "Run with PowerShell."
3. If Windows blocks it, open PowerShell as admin and run:
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   then try again.

The installer detects your Stardew Valley install, installs SMAPI if it's
missing, copies the mod into your Mods folder, walks you through Twitch
credential setup, checks for Tikfinity, and shows you every OBS overlay URL
at the end.

MAIN FEATURES (apply the bullet-list toolbar button after pasting)
------------------------------------------------------------
Viewers earn points by chatting, watching, subscribing, gifting subs, cheering bits, and raiding
Full in-chat shop: !balance, !shop, !buy <command>, !info <command>
Dozens of sabotages and blessings -- weather chaos, monster spawns, crop destruction, player debuffs, tool swaps, explosions, full-screen jump scares, and the 50,000pt Nuclear Chaos ultimate
Experimental TikTok integration (via Tikfinity) -- viewers earn points too, with named gifts triggering specific effects and a diamond-tier system for everything else
Experimental YouTube Live support via Streamer.bot (beta)
Live OBS browser-source overlays for chat, the shop, and TikTok gift redemptions
Togglable "100 Chicken Challenge"-style Animal Challenge mode chat can help or hurt
Alpha co-op multiplayer targeting -- give other streamers in your session their own chat-linked farmhand
Everything configurable in-game through Generic Mod Config Menu

Chat commands:
!balance -- check your chaos points
!shop -- browse every sabotage and blessing by tier
!buy <command> -- spend points on one
!info <command> -- details on a specific one
!give <user> <amount> -- transfer points (mods only)
!pointdrop -- timed giveaway: announces a claim keyword, awards points to everyone who types it in time (mods/broadcaster only)

OBS overlay URLs (once the mod is running):
Chat overlay: http://localhost:7373/chat
Shop sidebar: http://localhost:7373/
Mobile shop: http://localhost:7373/mobile
TikTok gift guide: http://localhost:7373/tiktok
TikTok live feed (vertical): http://localhost:7373/tiktoklive

Known limitations:
TikTok integration is experimental -- it depends on Tikfinity, a third-party bridge between TikTok Live and your PC, so behavior can shift if Tikfinity or TikTok's own Live platform changes.
YouTube integration is beta -- chat/membership/Super Chat points all work, but bot replies don't post back into YouTube chat yet (console log only); see the GitHub README for the Streamer.bot setup needed to enable that.
Multiplayer targeting is alpha and untested in a real multiplayer session. Input/screen-based effects (bans, jump scares, warps, and similar) only land on a co-op farmhand if they also install this mod themselves; everything else (money, buffs, inventory, monster spawns) redirects with no extra setup.
